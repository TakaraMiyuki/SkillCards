# 技能卡 SkillCards

Minecraft Java 26.2 / NeoForge 26.2 主动技能卡模组（测试版 0.1.0-beta），与[猎人游戏 Manhunt](../Manhunt) 联动。

手持卡片**右键发动**，成功后该卡进入冷却（物品图标转灰）；发动失败（如范围内没有猎人）**不进入冷却**。14 张卡按稀有度分四档，全部数值可在 `CardConfig.java` 中调整。

## 安装

- 模组 jar：`build/libs/skillcards-0.1.0-beta.jar`，与 `manhunt-0.1.1.jar` 一起放入 NeoForge 26.2 实例的 `mods/` 文件夹（服务端/客户端都装）。
- 依赖：NeoForge `[26.2.0.82,)`（26.2.0.88 实例可正常加载）、Minecraft `[26.2]`、**manhunt `[0.1.1,)` 与 飞翔 flying_enchant `[1.2.0,)`（均为可选依赖）**。
  - 不装 manhunt 也能加载：以"猎人"为目标的卡自动回退为对范围内**所有敌对生物**生效。
  - 不装飞翔模组时，海王之翼提示无法发动（不进冷却），其余卡片不受影响。
  - 客户端建议同样安装飞翔模组，否则疾跑+跳跃突进的按键手感可能不生效。
- 获取方式：创造模式物品栏"技能卡"标签页，或 `/give @s skillcards:xiangyu` 等（id 见下表）。
- **tooltip**：常驻显示 稀有度（品级色）/ 效果简介 / 冷却时间；**按住 Shift** 追加展开"使用后效果"（浅色字）。

## 管理员指令（权限等级 2）

| 指令 | 作用 |
|---|---|
| `/skillcards cleareffects [<targets>]` | 清除目标的全部技能效果：内存状态（神罚标记/飞行/诅咒/圣树/罗盘干扰/蓄力）、蓄力减速与诅咒最大生命减半、**赤鳞永久加成（生命上限与饥饿上限重置）**、卡牌施加的药水效果，并跨维度清除全部魔兔。默认 @s，可用选择器如 `@a`。 |
| `/skillcards refresh [<targets>]` | 立刻刷新目标背包内全部技能卡的冷却。默认 @s。 |

## 提示规则

- 发动成功：行动栏提示"发动：卡名"（卡名按品级着色）。
- 效果结束：有持续时间的卡（响玉/绽放/神罚/达芙妮/盲点/海王/诅咒/圣树）到期时提示"效果结束：卡名"+ 音效；即时卡（虹星/麒麟/三世/艾丝缇/赤鳞/纱幕）不提示结束。
- 冷却完毕：背包（含副手）内的技能卡冷却结束时提示"冷却完毕：卡名"+ 音效。
- 发动失败（范围内没有目标 / 未装飞翔模组等）不进入冷却并提示原因。

实现说明：

- **盲点** 的罗盘干扰通过 Manhunt 0.1.1 的 `CompassManager.targetDecorator` 钩子实现，只在 manhunt 已加载且对局中生效。
- **海王之翼** 通过注册表软引用飞翔模组的 `flying_enchant:flying` 状态效果（疾跑+跳跃突进，与飞翔附魔同一套移动方式），无编译期依赖；效果被牛奶等提前移除时同样触发到期缓降。
- **目标回退**：未安装 manhunt 时，纱幕/绽放/麒麟/三世秘传/达芙妮对范围内所有敌对生物（`Enemy`）生效；魔兔只追敌对生物，不再咬玩家。
- **纱幕烟雾团**：发动后在原地生成一团黑灰烟雾（半径 6 格、高 4 格、持续 30 秒，全服上限 12 团，`/skillcards cleareffects` 可清场），由服务端每 3 刻渲染。
- **粒子位置**：除神罚头顶标记外，全体粒子效果的释放位置统一向玩家身前偏移半个身位（`CardConfig.PARTICLE_FRONT_OFFSET`），避免第一人称遮挡。
- **卡牌描述**：Shift 展开的详细文案与《卡牌一览》"使用后效果"列逐字一致；关联全局效果的卡（鬼人/狂舞/麒麟/燃火/沸血之矛）在卡面下单独标注全局效果说明（浅青色）。
- **全局效果 HUD**：持有任意全局效果时，屏幕下沿（物品栏上方）显示一行小字，如 ［剑舞］12/20 ［狂剑］2/5 ［灼烧］1/5（服务端每 0.5 秒同步，变化才发包）。
- **燃火**：无论扇形范围内有无目标都可发动（不进入失败分支）。
- **主动/被动卡**：主动卡需手持右键发动；**被动卡放入背包（含副手）即自动生效**，右键无效，tooltip 标注"被动卡"。
- **全局效果·灼烧**：每层使目标着火时受到的火焰伤害 +1 点；着火时每 3 秒自动 +1 层（上限 5 层），火熄灭后存续 3 秒；不同卡来源互相叠加（麒麟/燃火/沸血之矛）。
- **全局效果·剑舞**：每层 +3% 近战攻速；每次叠加后重置衰减计时；**每 3 秒未再次叠加只掉 1 层**（上限 20 层）；不同卡来源互相叠加（鬼人/狂舞）。
- **全局效果·狂剑**：每层近战伤害 +1（上限 5 层）；由狂舞按 4:1 转换剑舞获得，1.5 秒未叠加剑舞清空。
- **主动/被动卡**：主动卡需手持右键发动；**被动卡放入背包（含副手）即自动生效**，右键无效，tooltip 标注"被动卡"。
- **全局效果·灼烧**：每层使目标着火时受到的火焰伤害 +1 点；着火时每 3 秒自动 +1 层（上限 5 层），火熄灭后存续 3 秒；不同卡来源互相叠加（麒麟/燃火/沸血之矛）。
- **全局效果·剑舞**：每层 +3% 近战攻速；每次叠加后重置衰减计时；**每 3 秒未再次叠加只掉 1 层**（上限 20 层）；不同卡来源互相叠加（鬼人/狂舞）。
- **全局效果·狂剑**：每层近战伤害 +1（上限 5 层）；由狂舞按 4:1 转换剑舞获得，3 秒未叠加剑舞清空。
- **HUD 位置**：`CardConfig.HUD_X_OFFSET / HUD_Y_OFFSET` 可调整全局效果小字的位置（默认居中、物品栏上方 46 像素）。
- **盲点发光抑制**：Manhunt 会给逃生者每 40 刻重挂常驻发光（分色队伍），盲点发动期间逐刻移除自己的发光，效果结束后由 Manhunt 刷新自动恢复——这就是与 Manhunt 的兼容点。
- **霜凪冻结表现**：手动拉满目标冻结刻度呈现"陷入细雪"血条（不处于细雪中时原版不会造成冻结伤害），0.5 点/秒由模组自行施加。
- **本能模式红色轮廓**：通过独立计分板队伍 `skillcards_red_glow` 染色，到期/发光消失自动移出队伍。
- **哈斯卡/过载的攻速**：通过 `ATTACK_SPEED` 属性百分比修饰符实现，效果结束自动移除。
- **艾丝缇的赐福** 蓄力期间末影粒子以玩家为中心向内敛聚，传送发动前一瞬向外炸开（音效：监守者蓄能）。
- **赤鳞之跃动** 的永久加成用 NeoForge Attachment（`copyOnDeath`）持久化，并在登录/重生/换维度时自动重挂属性修饰符；饥饿上限靠服务端每 0.5 秒钳制 `foodLevel` 实现（吃食物超过上限会被立刻压回）。
- **达芙妮之灾厄** 的魔兔生命周期与标记写入实体附加数据，服务器重启后到期仍会正确清理；分裂上限按批次（castId）在 64 格半径内计数；移速经 `CardConfig.DAFUNI_BUNNY_MOVEMENT_SPEED` 调整（默认接近玩家疾跑）。
- 临时状态（神罚标记、蓄力、飞行、诅咒、罗盘干扰计时）保存在服务端内存，**玩家重登后失效**（测试版取舍）；药水类效果遵循原版存续规则。

## 改数值

全部集中在 `src/main/java/com/example/skillcards/CardConfig.java`（时长/半径/伤害/上限/移速比等），改完 `./gradlew build` 重新出包。冷却时间在 `registry/Card.java` 枚举里。

## 测试清单（进服后逐项人工验证）

准备：装好两个模组 → 起一局 `/manhunt start random 1`（1 猎人 1 逃生者），或直接给双方发卡测试。建议用 `/give` 每人一套 14 张。

- [ ] **tooltip**：卡片悬停显示 稀有度（品级色）/ 效果简介（白字）/ 冷却；按住 Shift 追加展开"使用后效果"（浅灰字）。
- [ ] **提示与音效**：每张卡发动时行动栏出现"发动：卡名"+ 音效；响玉/绽放/神罚/达芙妮/盲点/海王/诅咒/圣树到期提示"效果结束"+ 音效；背包内卡片冷却结束提示"冷却完毕"+ 音效。
- [ ] **响玉**：绿+白玉尘螺旋上升，血条快速回复；8 秒后提示效果结束；卡图标转灰 3 分钟。
- [ ] **纱幕**：猎人在 20 格内 → 猎人屏幕变黑 10 秒、移速下降 2 秒；五层黑烟环扩散；原地出现半径 6 格、高 4 格的黑灰烟雾团并持续 30 秒后消散；无目标 → 提示且不进冷却。
- [ ] **绽放**：近身猎人被弹开；自身多出 10 颗黄心（吸收）与更高血上限（10 秒）；粉绿粒子从玩家身上炸开并外扩；30 秒后提示结束。

## 开发

- 构建插件 ModDevGradle 2.0.146 / Gradle 9.2.1 / JDK 25；编译期 NeoForge **26.2.0.82**（0.88 有 NFRT 重编译问题），运行依赖 `[26.2,)` 不受限。
- 编译依赖 `../Manhunt/build/libs/manhunt-0.1.1.jar` 与 `../Flying/build/libs/flying_enchant-1.2.0.jar`（`build.gradle` 的 `implementation files(...)`，后者仅供开发环境冒烟验证联动，代码不直接引用其类）；若两者重新构建版本变化，需要同步调整该路径。
- 无玩家冒烟测试：环境变量 `SKILLCARDS_SMOKETEST=1` 执行 `./gradlew runServer`，自动校验 14 张卡注册与罗盘钩子后关服。
- 占位贴图由 `tools/gen_assets.py` 生成（16×16，按稀有度配色），替换 `assets/skillcards/textures/item/*.png` 即可换正式卡面。

## 已知限制（测试版）

- 海王之翼依赖飞翔模组（flying_enchant）：未安装时该卡无法发动（提示且不进冷却）；如需在无飞翔环境下回退为原版式飞行，可在 `HaiWangCard` 换用 NeoForge `CREATIVE_FLIGHT` 属性。
- 卡牌为可重复使用 + 冷却模型，未做卡组/GUI 系统。
- 神罚的"20 点"在伤害管线后段覆写（`LivingDamageEvent.Pre`），护甲/吸收会继续作用于这 20 点（即对高护甲目标也恰好扣 20 点血量）。
- 临时卡牌状态不跨服务器重启保存；进行中的蓄力/飞行在重启后丢失。
- 魔兔的分裂计数按 64 格半径扫描，极端情况下（兔群被拉开很远）可能略微超出 60 上限。
- 三世秘传默认不偷 Manhunt 两个罗盘（防止破坏对局核心机制），可在 `CardConfig.SANSHI_EXCLUDE_CORE_ITEMS` 关闭。
